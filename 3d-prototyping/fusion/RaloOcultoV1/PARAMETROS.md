# Parâmetros principais

| Parâmetro | Valor inicial | Função |
|---|---:|---|
| `TOTAL_LENGTH_MM` | 900 | Comprimento total |
| `DRAIN_WIDTH_MM` | 78 | Largura da tampa |
| `MODULE_COUNT` | 3 | Quantidade de partes |
| `TOP_PLATE_THICKNESS_MM` | 5.5 | Espessura da superfície |
| `RIB_HEIGHT_MM` | 8 | Altura dos reforços |
| `CROSS_RIB_PITCH_MM` | 40 | Distância entre nervuras |
| `SLOT_WIDTH_MM` | 3.2 | Largura da passagem de água |
| `SLOT_LENGTH_MM` | 28 | Comprimento de cada ranhura |
| `CONNECTOR_CLEARANCE_MM` | 0.35 | Folga dos encaixes |
| `BUMPS_ENABLED` | True | Ativa/desativa antiderrapantes |
| `FILTER_ENABLED` | True | Cria os cartuchos conceituais |
| `CREATE_TEST_COUPON` | True | Cria o cupom curto |

Para o primeiro encaixe físico, normalmente vale aumentar `CONNECTOR_CLEARANCE_MM` para 0,45–0,55 mm caso a impressora esteja deixando os encaixes apertados.
